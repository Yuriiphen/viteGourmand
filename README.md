# Installation du projet Vite & Gourmand

## Prérequis

* XAMPP (Apache + MySQL + PHP)
* Navigateur web

## Installation

1. Copier le dossier `viteGourmand`dans :
   `xampp/htdocs/`

2. Lancer le panneau de contrôle XAMPP puis démarrer :

    Apache
    MySQL

3. Ouvrir phpMyAdmin :
   http://localhost/phpmyadmin

4. Créer une base de données nommée :
   `vite_gourmand`

5. Importer le fichier `vite_gourmand.sql` :
   Onglet **Importer** → sélectionner le fichier → exécuter

6. Vérifier le fichier `db.php` :

   
   host : localhost
   utilisateur : ECF
   mot de passe : ECF123
   base : vite_gourmand
   port : 3307
   le port peut varier selon la configuration.

## Lancement

Dans un navigateur :
http://localhost/viteGourmand
